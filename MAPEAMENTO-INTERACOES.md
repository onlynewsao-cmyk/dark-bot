## 🎯 Como funciona a seleção de GIF

```
1. Utilizador usa !comando
2. GIF_QUERIES mapeia comando → acção (e.g. !tapa → slap)
3. resolveCategory() busca as queries genéricas (g:) + anime (r:, t:)
4. fetchCandidates() consulta TODAS as fontes EM PARALELO:
   ├── Reddit (queries genéricas) ← NOVO
   ├── Giphy Genérico (queries genéricas) ← NOVO
   ├── Tenor (queries genéricas sem "anime") ← MELHORADO
   ├── Giphy (queries genéricas sem "anime") ← MELHORADO
   ├── otakugifs (anime reactions)
   ├── nekos.best (anime reactions)
   ├── purrbot (anime reactions)
   ├── waifu.pics (anime reactions)
   ├── some-random-api (anime reactions)
   └── nekos.life (anime reactions)
5. Ordenação: genéricas frescas > anime exato > anime vizinho > repetidos
6. Tenta até 4 candidatos → bufferToWhatsappMp4() → gifPlayback: true
```
